# AEVORIO 实际浏览器截图

此目录中的截图仅保存在本机，由 Git 忽略，不随源码提交。此说明文件保留在版本库中。

此目录保留 50 张正式验收截图，baseline 目录保留 6 张修改前基准截图。全部图片来自本机实际 Chromium 页面。

| 文件组 | 内容 |
| --- | --- |
| baseline | 三个公开页面修改前的首屏与完整页面 |
| home、products、about 的 first-viewport 和 full-page | 三个公开页面的正式首屏与完整页面 |
| home、products、about 的尺寸文件 | 三页分别在八种指定窗口尺寸下的完整页面，共 24 张 |
| admin-overview | 后台在八种指定窗口尺寸下的概览 |
| admin-edit | 产品、类别、板块、公共配置和页面元信息的实际编辑界面 |
| admin-login | 正式后台登录界面，不包含填写后的凭据 |
| admin-coverage | 全部资源映射和最近一次实际覆盖状态 |
| products-dialog-320 | 窄窗口中的产品详情弹窗 |
| maintenance-replacement-dialog | 临时图片替换的真实显示，正式内容已恢复 |
| content-failure-state | 独立故障测试服务的显示，不代表正式服务发生故障 |
| review-closing、review-quote | 结尾导航与引言板块的视觉核对 |

八种窗口尺寸为 1920×1080、1600×900、1440×900、1280×800、1024×768、768×1024、390×844、320×700。

后台截图使用临时验收账户。交付前该账户和会话已撤销。正式登录凭据只保存在后端受限目录。
